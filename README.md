This is the special profile repository for
[ShxdowCollective](https://github.com/ShxdowCollective). The file in `profile/`
is what visitors see when they land on the org page. Keep it atmospheric,
accurate, and useful. No corporate fog.

## what lives here

| path | purpose |
| --- | --- |
| [`profile/README.md`](profile/README.md) | The external org profile |
| [`assets/brand/`](assets/brand/) | Reusable banners, logos, and icons |

The profile points people toward the actual signal:
[shxdow.cc](https://shxdow.cc),
[Voidware](https://github.com/ShxdowCollective/voidware), and the
[ShxdowCollective GitHub](https://github.com/ShxdowCollective).

## editing the signal

1. Edit [`profile/README.md`](profile/README.md) for public copy, layout, and links.
2. Reuse files from [`assets/brand/`](assets/brand/) with relative paths.
3. Keep links real and claims grounded. Do not add invented canon or product lore.
4. Preview the Markdown on GitHub before merging.

The profile is intentionally plain Markdown with a little HTML for alignment and
image sizing. Preserve the dark-theme-friendly artwork, the spaced
`w e _ a r e _ t h e _ s h x d o w s...` line, and the
`d o _ n o _ h a r m / t a k e _ n o _ s h i t` sign-off when reshaping it.
